# Autonomi

**A decentralised data and communications network, owned by no one.**
Permanent, private, post-quantum storage across the spare capacity of everyday
devices. Pay once, keep it for good - no servers, no subscriptions, no one else
holding the keys. Built by MaidSafe over 20 years; stewarded by the Autonomi Foundation.

### Start here
- **Build on it** - the SDK and a quickstart: [docs.autonomi.com](https://docs.autonomi.com)
- **Read the whitepaper** - [autonomi.com/whitepaper](https://autonomi.com/whitepaper)
- **Try it** - the app and Indelible at [autonomi.com](https://autonomi.com)
- **Point your agent at it** - llms.txt and clean markdown docs: [autonomi-llm-docs](https://github.com/WithAutonomi/autonomi-llm-docs)
- **Join the community** - [Discord](https://discord.gg/autonomi)

### The core repositories
| Repo | What it is |
|---|---|
| [self_encryption](https://github.com/WithAutonomi/self_encryption) | Self-encrypting, content-addressed storage - the peer-reviewed core |
| [ant-node](https://github.com/WithAutonomi/ant-node) | The post-quantum network node |
| [saorsa-core](https://github.com/WithAutonomi/saorsa-core) | P2P networking: DHT, QUIC transport, MCP integration |
| [ant-client](https://github.com/WithAutonomi/ant-client) | Read from and write to the network |
| [ant-sdk](https://github.com/WithAutonomi/ant-sdk) | Build on Autonomi from Go, Python, JS/TS, Swift, Kotlin and more - via FFI, a daemon and an MCP server |

### Why it's different
Post-quantum end to end (ML-KEM-768, ML-DSA-65, ChaCha20-Poly1305, BLAKE3),
content-addressed and self-encrypting, permanent, and owned by no company or
contract. Open source, dual-licensed MIT / Apache-2.0. Everything's here - just build.
